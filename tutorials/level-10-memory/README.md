# Level 10 — Memory Management

## Trạng thái

**Đang chuẩn bị — học xong Level 0–1 rồi quay lại**

> **Cực kỳ quan trọng cho Unity MMORPG** — GC spike là nguyên nhân hàng đầu gây giật lag trong game. Không học lướt. Liên hệ trực tiếp Unity GC spikes.

## Mục tiêu

Hiểu CLR memory model, GC generations (Gen0/1/2, LOH), vòng đời object, `IDisposable` / Dispose pattern, memory leaks (đặc biệt event leaks), và object pooling — áp dụng để giảm GC pressure trong Unity.
