# Capstone — Unity MMORPG / Game Architecture

## Trạng thái

**Đang chuẩn bị — học xong Level 0–1 rồi quay lại**

Hoàn thành sau Level 0–21. Mỗi milestone gồm: Requirements → Architecture diagram → Tasks → Expected result → Exercises → Hints → Complete solution → Code review checklist.

## Mục tiêu

Xây dựng kiến trúc game Unity kiểu MMORPG, tổng hợp OOP, generics, SOLID, patterns, async, networking, persistence, memory/GC và tối ưu performance.

## Ước lượng

Tích hợp kiến thức toàn lộ trình (~412 giờ học trước đó). Thời gian capstone tùy track (Fast / Normal / Deep).

## Milestones (theo plan)

1. **Core Architecture** — DI container, service layer, game loop structure
2. **Entity System** — ECS-style hoặc component-based entity, generics, interfaces
3. **Inventory** — generic collections, SOLID, events
4. **Quest System** — state pattern, observer, serialization
5. **Combat System** — strategy pattern, command pattern, object pooling cho VFX/projectiles
6. **Networking** — REST/WebSocket client, async/await, serialization JSON
7. **Persistence** — save/load, file IO, serialization, versioning
8. **Optimization** — profiling, GC tuning, pooling audit, benchmarking
