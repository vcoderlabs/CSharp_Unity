# C# Tutorials — Từ Zero đến Unity

Lộ trình học theo [`plan.md`](../plan.md). Mỗi level có bài giảng + bài tập bằng **tiếng Việt**, giải thích rõ ràng.

## Cách học

1. Đọc **Mục tiêu** và **Khái niệm** trước khi làm bài.
2. Tự làm **Bài tập** trước khi xem Gợi ý / Đáp án.
3. Làm **Thử thách** nếu còn thời gian.
4. Trả lời **Kiểm tra kiến thức** cuối mỗi chương.

## Cấu trúc mỗi bài học

| Mục | Ý nghĩa |
|-----|---------|
| Mục tiêu học | Bạn sẽ làm được gì sau bài này |
| Điều kiện tiên quyết | Cần biết gì trước |
| Khái niệm | Giải thích lý thuyết |
| Mô hình tư duy | Hình dung trong đầu |
| Cú pháp | Code mẫu (nếu có) |
| Ví dụ Cơ bản → Trung cấp → Nâng cao | Tăng dần độ khó |
| Lỗi thường gặp | Tránh sai sớm |
| Gỡ lỗi | Cách đọc lỗi / debug |
| Best practices | Thói quen tốt |
| Bài tập | Luyện tay |
| Gợi ý / Đáp án / Giải thích | Chỉ mở khi bí |
| Thử thách | Đi xa hơn |
| Thực tế & Unity | Liên hệ game/dev |
| Kiểm tra kiến thức | Ôn nhanh |
